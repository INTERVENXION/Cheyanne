## 想换成自己的图片？

程序按**文件名**加载表情，替换时保持文件名一致即可：

| 文件名 | 触发时机 |
|---|---|
| `idle.png` | 默认待机 |
| `happy.png` | 模型输出 `"emotion": "happy"` |
| `sad.png` | `"sad"` |
| `angry.png` | `"angry"` |
| `surprised.png` | `"surprised"` |
| `shy.png` | `"shy"` |
| `talking.png` | 发送消息后、等待回复时 |

### 格式要求

- **PNG，带透明背景（alpha 通道）**
  窗口外形是用 alpha 通道生成的遮罩，不透明的图片会变成一个方块。
- 透明区域要有真正的 `alpha = 0`，不要用白底代替。
- 建议尺寸：高 700～900 px，宽度按比例。
- 各张图宽高可以不同，程序会按实际尺寸调整窗口大小。

当前随仓库附带的尺寸供参考：

| 文件 | 尺寸 |
|---|---|
| `idle.png` | 419 × 725 |
| `happy.png` | 509 × 761 |
| `sad.png` | 552 × 752 |
| `angry.png` | 485 × 722 |
| `surprised.png` | 466 × 732 |
| `shy.png` | 631 × 876 |
| `talking.png` | 419 × 725 |

### 缺图会怎样

只放 `idle.png` 也能运行——找不到对应表情的文件时，会回落到 `idle`，
不会崩溃、也不会报错刷屏。

### 打包 exe 时

`XiaAnPet.spec` 会把整个 `Image/` 目录复制到 `dist\`，
所以打包后 `dist\Image\` 里必须有这些文件，否则启动后看不到人物。

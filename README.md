# Cheyanne
本项目灵感和人设，角色图片源自散爆网络制作的游戏：《少女前线2：追放》及其附属IP《少女前线》，仅作同人二创，不收取任何盈利费用。

该项目是以《少女前线2：追放》中的人物角色"夏安"为原型，制作的一个小小聊天桌宠，已内置人设提示词，当前版本仅有聊天功能;

如需要运行项目，需要填写自己的LLM的apikey，例如deepseek,chatgpt,gemini等大模型(个人推荐使用gemini);
